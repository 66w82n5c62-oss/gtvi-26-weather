Location & phone use

Only Start asks for location. GPS fixes stay in memory on this device; there is no location history or upload. Weather requests use the uploaded route’s sample points. Stop clears live progress. Switching stages stops tracking.

Keep this page visible. iPhone browsers can suspend GPS and timers when the screen locks or you switch apps; adding to the Home Screen does not guarantee background tracking. On return, we reacquire GPS and exclude the gap from pace. This is a weather companion, not turn-by-turn navigation.

Location is sampled about every 20 seconds with low-power accuracy requested. Poor fixes and off-route positions hold ETAs. At loops, select the correct stage and Start near its beginning. Weather is cached in this tab; reloading clears the route and cache. Stationary detection needs about 90 seconds; use Pause for longer breaks.
